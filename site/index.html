interactive

A poll is a slide

No second tab, no separate account, no copy of your questions somewhere else. Write the Markdown on the left and the real slide appears on the right. Add a block with a button, then click the slide to open voting.

The same code that runs your talk, running in your browser. Open the full playground · Play the demo talk

poll and multi

Live bars. Mark a right answer and it stays hidden until you reveal it.

estimate

Everyone guesses a number. Every guess becomes a dot, then the average, then the truth.

rounds

The same question over a list, one result per round.

sentence

The room writes a sentence one word at a time, like a language model picking the next token.

questions

Anonymous questions with upvotes. You approve them before they reach the screen.

component

Anything else, in a JavaScript file next to your talk. Your agent can write it.

agent ready

Your agent writes it. You give it.

Quorum is built so an agent can do the authoring the way it edits code: read the format, write the files, check its own work. You stay the speaker.

  1. you

    Ask

    Describe the talk, the room and where people should take part.

  2. agent

    Write

    It writes talk.md and any components the talk needs.

    talk.md
  3. agent

    Check

    It runs the checker and fixes every warning, slide by slide.

    quorum check --json
  4. you

    Preview

    You watch it update with a simulated audience and ask for changes.

    quorum preview
  5. you

    Present

    A public link, a QR code and your panel. The live talk is yours to run.

    quorum live

a prompt to start from

Make me a 20-minute Quorum talk about how bread rises, with a warm-up poll, an estimate with a reveal, a word cloud and a questions slide. Run quorum check --json until it reports no warnings.

Paste it into Claude Code or any coding agent once Quorum is installed. 
terminal$ npm install -g github:JBoixCampos/quorum
$ quorum skill            # Claude Code, every folder
$ quorum skill --to path  # another agent's skills

  • quorum skill

    Teaches Claude Code to write and check a talk and build components for it, in any folder.

  • AGENTS.md

    quorum new puts the format, the commands and the rules in every talk folder.

  • llms-full.txt

    The whole format and component reference in one file. Full or index.

  • check --json

    Every problem with its slide number, and a non-zero exit until there are none.

  • components/*.js

    Plain ES modules with a small API: mount(el, ctx). No build step to get wrong.

  • .quorum/

    Votes and presenter keys live here, and agents are told never to touch it.

Set up your agent, step by step

interactive + agent ready

Build what nobody has built yet

Add audience: to a component and every phone gets a text box, a number field or a list of options. Your code, or your agent's, gets the answers. Quorum handles the rest: opening and closing, one answer per phone, simulated answers in the preview, and keeping the screen and your panel in sync.

The examples include a word cloud and a next-word explorer that asks a language model on your own laptop for its ten most likely words, so the room can watch it think.

How components work See the examples

talk.md::: component word-cloud
audience: text
prompt: One word: how do you feel about AI?
:::components/word-cloud.jsexport default {
  mount(el, ctx) {
    const paint = (c) => {
      el.textContent = c.answers.values.join(' ');
    };
    paint(ctx);
    return { update: paint };
  },
};

private by design

No accounts, no cloud

Your laptop is the server. Nothing about your talk or your audience leaves the room unless you put it there.

Your laptop is the server

One command starts it, opens a public link through a tunnel and puts the QR code on your slides. Votes stay in your talk folder until you delete them.

Anonymous by design

No names, no sign-up, no app. Each phone gets a random id so it votes once. Notes and right answers never reach phones before you reveal them.

Ready for any room

No public link? People on the same wifi still join. Nobody can join at all? quorum export gives you the talk without the audience slides.
