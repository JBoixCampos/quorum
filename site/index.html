Every block, with examples

Build what nobody has built yet

Add audience: to a component and every phone gets a text box, a number field or a list of options. Your code gets the answers. Quorum handles the rest: opening and closing, the QR code, one answer per phone, simulated answers in the preview, and keeping your screen and your panel in sync.

The examples include a word cloud and a next-word explorer that asks a language model running on your own laptop for its ten most likely words, so the room can watch it think.

How components work · See the examples

<!-- talk.md -->
::: component word-cloud
audience: text
prompt: One word: how do you feel about AI?
:::

// components/word-cloud.js
export default {
  mount(el, ctx) {
    const paint = (c) => {
      el.textContent = c.answers.values.join(' ');
    };
    paint(ctx);
    return { update: paint };
  },
};

Your agent writes it. You give it.

A talk is a Markdown file and a few small JavaScript files, so an AI agent can write it, check it and build new interactions for it, the way it edits code. You watch it take shape in quorum preview, ask for changes, and give it to a real room.

  • A talk folder knows the rules. quorum new adds an AGENTS.md that tells an agent the format, the commands and what not to touch.
  • The docs fit in one file. Point any agent at llms-full.txt, or at the short index in llms.txt.
  • It can check its own work. quorum check --json lists every problem with its slide, and fails until there are none.
  • A ready-made skill in agents/quorum/SKILL.md teaches an agent to write and check a talk and build components for it.

How to work with an agent

Make me a 20-minute Quorum talk about how bread rises, with a warm-up poll, an estimate with a reveal, a word cloud and a questions slide. Run quorum check --json until it reports no warnings.

Paste it into Claude Code or any coding agent, in a folder where Quorum is installed. Change the topic and the blocks to suit your talk.

No accounts, no cloud

Your laptop is the server

One command starts it, opens a public link through a tunnel and puts the QR code on your slides. Votes stay in your talk folder until you delete them.

Anonymous by design

No names, no sign-up, no app. Each phone gets a random id so it votes once. Your notes and the right answers never reach the phones before you reveal them.

A panel just for you

Your notes, the next slides, how many people are in, the questions waiting for approval, and how you are doing on time. Before the day, quorum preview fills the room with simulated people.
