How it works

Four steps, one folder

A talk is a Markdown file in a git repository. Your agent writes in it, Studio edits it, and every change is a line you can read in git diff.

  1. 01

    Start

    Use the template, or one command. You get the talk, instructions for agents and checks on every push.

  2. 02

    Your agent writes it

    Claude Code, Codex or Cursor, on your computer or in the cloud, writes the slides and checks its own work.

  3. 03

    You shape it

    In Studio: type on the slide, drag in polls and charts, try other layouts, ask your agent for more.

  4. 04

    Present or export

    A link and a QR code for the room, your slides and your panel. Or an editable PowerPoint file.

02 · Write

Your agent writes it

The talk is plain Markdown, so a coding agent writes it the way it writes code. It reads the instructions in the folder, writes the slides, runs the checker and fixes what it finds. No copying slides back and forth.

  • Nothing to set up. Every talk has an AGENTS.md with the format and the rules.
  • It checks its own work. Mistakes, poor contrast and slides that do not fit, with the slide number.
  • In the cloud too. An agent with your repository pushes a branch; the checks run on GitHub.

03 · Shape

You shape it in Studio

The real slide in the middle, your slides on the left, what you selected on the right. Studio edits the same files as your agent and shows its changes as they are saved.

  • Type on the slide, and drag blocks, cards and pictures where you want them.
  • Drag in what the room does: polls, quizzes, guesses and questions, edited with a form.
  • See it other ways. Quorum lays a slide out as cards, steps or a chart, instantly. For more, Studio writes the request for your agent.
  • Undo, and git. Every change is a plain edit to your files.

04 · Give

Present it live

Present in Studio starts the talk on your laptop: a public link (or your local network), the QR code on your slides, the presentation to share or project, and your panel. People answer from their phones, with no app and no account.

04 · Or export

A PowerPoint file, too

Export writes a .pptx with real, editable text, shapes, tables and charts, your notes and your transitions. Slides where the audience answers point to Quorum, or, after the talk, show what the room answered.

So Quorum is also how your agent makes a PowerPoint deck, with nobody voting at all.

Principles

Yours, from start to finish

Your laptop is the server, your repository is the storage, and your agent is the AI. Quorum has none of its own.

Your laptop is the server

Present opens a public link through a tunnel, or uses your local network. Votes stay in your folder until you delete them.

Anonymous by design

No names, no sign-up, no app. Notes and right answers never reach phones before you reveal them.

Plain files, in git

Markdown and a few small JavaScript files. Teams and agents work on branches, and slides merge one by one.

Get started

Start a talk

You need Node.js 18 or newer. Both ways give you the same folder.

On GitHub

Use the template

A repository of your own, with the talk, the agent instructions and the checks. Clone it, or give it to an agent in the cloud.

$ git clone <your new repository>
$ cd my-talk
$ npm install
$ npm run studio
Use the template

On your computer

One command

The same folder, made on your computer. Add --repo to start a git repository too.

$ npx github:JBoixCampos/quorum new my-talk
$ cd my-talk
$ npm install
$ npm run studio
